### ⭐ **VIT Faculty Ratings Extension**
Chrome extension that enhances the FFCS course registration experience by injecting faculty ratings directly into the portal.

**Key Features:**
- Real-time DOM injection for dynamically loaded content
- MutationObserver for SPA compatibility
- Local CSV-based rating database with search
- Zero external dependencies, lightweight execution

**Tech Stack:** JavaScript, Chrome Extension APIs, DOM Manipulation, CSV Parsing

🔗 **[Repository](https://github.com/akash-1969/vit-faculty-ratings-extension)**

### 🧠 **JobCopilot**
Privacy-first Chrome extension that serves as an intelligent career co-pilot for job boards — analyzes resumes and suggests matches.

**Key Features:**

- Job description matching and scoring algorithm
- Skill gap analysis
- Local-first architecture (no data leaves the browser)

**Tech Stack:** JavaScript, Chrome Extension APIs, PDF.js, Local Storage, Custom Matching Engine

🔗 **[Repository](https://github.com/akash-1969/job-copilot-extension)**
